# Ecommerce Baraka '25

A simple ecommerce application built with FastAPI as a sample project for Altschool Africa's Baraka '25 cohort.

## Overview

This project demonstrates core ecommerce functionality including product browsing, shopping cart management, and basic checkout features.

## Features

- Product catalog
- Shopping cart
- Order management
- User authentication (basic)

## Getting Started

### Prerequisites

- Python (v3.8+)
- pip

### Installation

```bash
git clone <repository-url>
cd ecommerce_baraka25
```

Create a virtual environment:

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

### Running the App

```bash
python app/main.py
```
